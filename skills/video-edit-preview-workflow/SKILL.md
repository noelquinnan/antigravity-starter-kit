# 视频剪辑试做与双屏对照预览 SOP

## 1. 核心铁律（每次必遵守）
1. **必须完整看完/听完原课全部参数，严禁瞎猜**：复刻教程时，必须先将原课完整语音听全（`ffmpeg` 转低码率单声道 mp3 后读取核对）并抽 2fps 关键帧核对视觉细节（节奏、时长、阴影/羽化、缝宽、曲线），记录完整参数清单后再动手。
2. **画面亮度与质感自检**：优先选高亮通透的高清原片，禁止无故压低不透明度或把画面搞得黑灰发蒙；生成后必须抽帧核查画面清晰度与对齐，确认无黑屏/错位后再交付。
3. **双输出交付**：
   - **剪映可编辑草稿（可选）**：如本机配置了 `pyJianYingDraft` 等草稿脚本，可同步写入用户的剪映草稿目录并做结构校验。
   - **1080p 可播放预览 MP4**：同步用 `ffmpeg` 渲染一份 1080p 预览 MP4，让用户无需打开剪辑软件也能立刻审片。
4. **内置浏览器弹出对照窗口（绝不直接甩 `.html` 源码）**：
   - 生成/更新本地左右双屏对照页 HTML（左边原教程，右边本次试做预览，带同步播放/暂停/重置按钮与 `?v=N` 防缓存参数）。
   - 启动轻量本地 HTTP 服务（如 `python -m http.server 8765 --bind 127.0.0.1`），并调用内置 `browser` 子智能体打开对照页供用户直接观看审判。

## 2. 出厂自检清单（交付前逐项核对）
- [ ] **原课参数核清**：确认全部隐藏图层（投影/羽化/闪黑/闪光/边框/文字层）与真实单镜时长。
- [ ] **节奏精准**：快进慢停、卡点间隔、单组时长严格对齐目标节奏。
- [ ] **构图与亮度过关**：抽 3 帧（起手/特效峰值/收尾）确认清晰无发灰。
- [ ] **一步弹窗验收**：渲染 1080p 预览 + 更新左右双屏对照页 + 内置浏览器直接展示。

## 3. 导演-剪辑师协作模式
- 用户负责审美拍板，智能体负责快速出 A/B 对比版或按口语化意见（如“节奏再快点 / 脸居中一点 / 换个转场”）快速迭代并刷新浏览器预览。
