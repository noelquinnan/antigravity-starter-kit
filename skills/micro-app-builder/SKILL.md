# 专属小工具极速开发与自动验收（micro-app-builder）

本技能将“轻量选型 + 现代 UI 规范 + 统一归档 + 内置浏览器实测验收”固化为标准闭环，杜绝过度设计和“写完不能点”的半成品。

---

## 1. 极简架构选型（严格遵守 KISS，拒绝冗余依赖）

按需求实际边界选择最轻方案，默认不引入几百 MB 的前端构建链：

| 需求类型 | 默认架构 | 产出文件 |
| :--- | :--- | :--- |
| **纯前端交互工具**（计算器、公式/电路可视化、刷题/背诵看板、倒计时、JSON/文本处理、记账/清单） | 零构建单文件 HTML5 + CSS3 + 原生 ES6（图标用内联 SVG） | `index.html` + `启动.bat` + `README.md` |
| **需读写本地磁盘 / 调用本地 CLI**（如 `ffmpeg`、`magick`、`pandoc`、`es`、`lms` 本地模型、Python 科学计算） | Python 标准库 `http.server`（或轻量 FastAPI）+ 单文件前端 | `server.py` + `index.html` + `启动.bat` + `README.md` |
| **重型前端组件需求**（仅当明确需要复杂富文本/大型状态树时） | Vite + 最小依赖 | 先向用户说明理由再建项目 |

---

## 2. UI 与交互底线（禁止廉价默认风）

1. **视觉与布局**：
   - 使用 CSS 变量统一定义配色、圆角、阴影与间距；正文行高清晰，主次操作按钮有明确视觉层级。
   - 适配桌面宽屏与窄屏（如侧边栏/分屏），严禁出现文字溢出、按钮错位或意外横向滚动条。
2. **交互与防丢数据**：
   - 纯前端工具默认接入 `localStorage`（大数据用 `IndexedDB`）实现刷新不丢数据，并提供「导出 JSON / 导入恢复」按钮。
   - 所有异步或批处理操作必须有明确的加载态、进度反馈与可读错误提示，不静默失败。
   - 涉及文件输入的工具优先支持**拖拽区域**与点击选择双入口。

---

## 3. 统一工具箱归档与一键启动

所有个人小工具默认归档至云盘统一目录（若用户指定其他项目路径则按用户要求）：

```text
~/Micro_Apps/
├── INDEX.md                 # 全部自制小工具总目录（每次自动追加）
└── <简洁工具名>\
    ├── index.html           # 界面入口
    ├── server.py            # 可选：需要本地能力时才创建
    ├── 启动.bat             # 双击自动起本地 HTTP 服务并打开浏览器
    └── README.md            # 功能简介与使用说明
```

- **`启动.bat` 标准写法**（纯前端用 `python -m http.server`，后端用 `python server.py`，自动选定空闲端口并 `start http://127.0.0.1:<port>`，避免 `file://` 协议导致的 CORS/模块加载报错）。
- **更新 `INDEX.md`**：每次新建工具后，自动追加一行 `| 日期 | 工具名 | 架构类型 | 一句话用途 | 路径 |`。

---

## 4. 自动化浏览器验收闭环（铁律：未实测不交付）

代码写完后，必须执行以下验收步骤，全部通过才算完成：

1. **启动本地服务**：以后台守护进程（`IsDaemon: true`）在 `127.0.0.1:<可用端口>` 启动该工具。
2. **内置浏览器实测**：调用 `browser` 子代理打开 `http://127.0.0.1:<port>` 并完成 4 项检查：
   - **零报错检查**：控制台无 `Console Error`、无未捕获异常、无 `404` 资源缺失。
   - **核心功能冒烟**：真实输入测试数据、点击主要交互按钮、验证输出与状态变化符合预期。
   - **持久化验证**：刷新页面后确认数据保留正常（若涉及本地存储）。
   - **视觉版式检查**：确认页面对齐、无遮挡、无文字溢出、无难看留白。
3. **闭环修复**：若浏览器验收发现任何报错或排版瑕疵，立即修复源码并重新验收，直到全部通过。
4. **交付给用户**：保持本地预览服务运行（方便用户直接点开体验），同时给出工具目录、一键 `启动.bat` 路径与核心功能说明。
