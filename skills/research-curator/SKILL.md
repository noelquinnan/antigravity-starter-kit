# 资料搜集与主动分类沉淀（research-curator）

本技能将「本机检索 + 全网多源核验 + 视频字幕提取 + 主动分类归档」打通为一条标准流水线，避免单源瞎猜和零散堆砌。

---

## 1. 接收任务后的第一步：主动分类与定范围

拿到主题后，先在脑中（并用 1 句话同步给用户）完成**自动分类**与**采集路由**：

| 分类目录 | 适用场景 | 重点输出形态 |
| :--- | :--- | :--- |
| `01_学业与实验` | 课程学习、论文文献、公式原理、实验/仿真调研 | 原理拆解 + 公式/代码 + 参考文献 + 常见考点/易错点 |
| `02_技术与选购` | 软件工具、开发方案、硬件选购、踩坑排错 | 核心结论 + 参数/优缺点对比表 + 避坑清单 + 选型建议 |
| `03_创作与剪辑` | 剪辑教程拆解、素材/插件参数、特效复刻、二创参考 | 分步操作拆解 + 参数清单 + 素材来源与版权说明 |
| `04_综合专题` | 不属于以上三类的跨领域主题 | 结构化摘要 + 多维对比 + 行动建议 |

**默认知识库根目录**：`~/Research_Hub/`（若用户明确指定了当前项目目录，则写入用户指定目录）。

---

## 2. 三路并发采集（按需组合，不盲目开浏览器）

### A. 本机已有资料路（先查本地，防重复劳动）
- 用 `es`（Everything CLI）快速检索本机是否已有相关 PDF、PPTX、DOCX、Markdown 或视频素材：
  ```powershell
  es -n 20 "关键词 ext:pdf;pptx;docx;md;txt"
  ```
- 找到关键本地文档时，用 `pandoc` 或轻量 Python 脚本提取核心文本纳入汇总，并在报告中附上 `file://` 路径。

### B. 全网权威信源路（多词并发 + 交叉核验）
- 并行发出 2～4 组差异化 `search_web` 查询（中英文结合、覆盖官方文档 / GitHub / arXiv / 专业评测 / 社区避坑）。
- **信源优先级**：官方文档 / 论文原文 / GitHub 源码 > 实测数据与技术社区 > 媒体评测 > 营销号（尽量过滤）。
- 仅当目标页面为 JS 动态渲染或需要交互查看时，再交由 `browser` 子代理打开读取，不要用浏览器替代普通搜索。

### C. 视频教程与网课路（不靠猜，直接扒字幕）
- 遇到 B 站、YouTube 等视频链接或教程时，调用本技能内置脚本一键提取并清洗字幕为纯文本：
  ```powershell
  python "~/.gemini/config/skills/research-curator\scripts\fetch_subs.py" "<视频URL>" --out "<输出目录>"
  ```
- 若视频无字幕且用户需要深度拆解，先告知用户再决定是否用 `yt-dlp` 下音频配合本地转写。

## 3. 防幻觉与质量验收铁律

在写入最终文档前，必须自检以下 5 条，不达标不交付：

1. **能下必下（禁止只甩链接）**：凡是公网可直接下载的原始文件（如官方 PDF 试卷、开源仓库真题/课件/代码、公开数据表），必须默认**直接批量下载并按子类别存进本专题 `assets/` 目录**，不要只列一堆链接让用户自己点。
2. **出处可追溯**：所有核心数据、参数、价格、版本号、文献观点必须附带可点击 URL 或本机 `file://` 路径；查不到确切来源的标注“待核实”，禁止编造。
3. **多源交叉验证**：涉及硬件选购、避坑结论、技术选型或学术定义时，至少交叉比对 2 个独立信源；若存在版本或时间差异，明确标注日期与适用版本。
4. **结构化呈现**：结论先行，能用对比表就不用大段散文；区分「已验证事实」与「社区主观评价」。
5. **严格去水**：剔除营销废话和重复段落，只保留可直接复用、可决策、可落地的信息。

## 4. 自动归档与目录沉淀规范

每次搜集完成后，自动在对应分类下创建专题目录：

```text
~/Research_Hub/
├── INDEX.md                              # 全库总目录（每次自动追加一行）
├── 01_学业与实验\
├── 02_技术与选购\
├── 03_创作与剪辑\
│   └── 2026-11-25_<简洁主题名>\
│       ├── README.md                     # 主报告（结论、对比表、分步要点、避坑）
│       ├── sources.md                    # 全部信源链接、抓取日期与关键原话摘录
│       └── assets\                       # 可选：清洗后的视频字幕、表格 CSV、参考图
└── 04_综合专题\
```

- **更新 `INDEX.md`**：若根目录尚无 `INDEX.md`，先创建表头 `| 日期 | 分类 | 主题 | 一句话结论 | 路径 |`；每次归档后自动追加一行相对路径链接，方便后续直接检索复用。
- **按需导出交稿格式**：若用户提出需要 Word 或 PDF，归档后再执行 `pandoc README.md -o <主题>.docx` 一键导出。

---

## 5. 回复用户的交付格式

1. **核心结论**：3～5 行内给出最关键的答案或选型/学习建议。
2. **核心对比或要点**：精炼展示最值得看的表格或分点。
3. **归档位置**：给出主报告 `README.md` 与 `INDEX.md` 的可点击 `file://` 链接，并说明已归入哪个分类目录。
